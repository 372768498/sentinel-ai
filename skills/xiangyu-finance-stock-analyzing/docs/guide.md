# 新手指南

---

## 这个 Skill 做什么？

分析美股个股，输出 10 维度综合评分（0-100 分）和 5 级评级（Strong Buy → Sell）。支持 6 个深度分析领域，生成中文 Markdown 报告。

**举个例子**：你想知道现在该不该买英伟达，输入「分析 NVDA」，2-3 秒后得到一份包含估值、技术面、市场情绪等 10 个维度的综合评分报告。如果想深入了解估值是否合理，再选「估值深度」，额外得到 DCF 内在价值估算。

---

## 如何调用？

**斜杠命令**（推荐）：

```
/xiangyu-finance-stock-analyzing
```

**自然语言**：

说「股票分析」「分析 AAPL」「stock NVDA」「分析股息」即可启动。

---

## 7 种分析模式

| 编号 | 模式 | 耗时 | 输出 |
|:----:|------|------|------|
| 0 | 快速分析 | 2-3s | 综合报告（10 维度评分） |
| 1 | 估值深度 | 8-12s | 综合报告 + DCF、历史估值、行业对比 |
| 2 | 成长性深度 | 8-12s | 综合报告 + 营收/EPS 趋势、PEG |
| 3 | 技术面深度 | 8-12s | 综合报告 + 多时间框架、买卖信号 |
| 4 | 基本面深度 | 8-12s | 综合报告 + 利润率趋势、杜邦分解 |
| 5 | 同行对比深度 | 8-12s | 综合报告 + 对比矩阵、竞争排名 |
| 6 | 股息深度 | 8-12s | 综合报告 + 安全评分、增长 CAGR |

---

## 使用流程

1. 调用 `/xiangyu-finance-stock-analyzing`
2. 输入股票代码或公司名称（如 `NVDA`、`特斯拉`）
3. 选择分析模式（点选选项或输入编号 0-6）
4. 等待分析完成，查看报告

---

## 输入输出

| 类型 | 路径 | 格式 | 说明 |
|------|------|------|------|
| 输入 | 交互式输入 | 文本 | 股票代码 + 模式选择 |
| 输出 | `{skill_dir}/runs/{ticker}-{时间戳}/output/` | Markdown | 综合报告（必有）+ 深度报告（深度模式） |

输出示例：

```
runs/nvda-20260226-211500/output/
├── NVDA-综合报告-2026-02-26.md
└── NVDA-估值-深度报告-2026-02-26.md    # 仅深度模式
```

## 评分体系

| 评分 | 评级 | 含义 |
|:----:|------|------|
| 80-100 | Strong Buy | 强烈买入 |
| 65-79 | Buy | 买入 |
| 50-64 | Hold | 持有 |
| 35-49 | Reduce | 减持 |
| 0-34 | Sell | 卖出 |
