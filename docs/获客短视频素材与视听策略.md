# Sentinel AI 获客短视频素材与视听策略 v1

## 目标

短视频第一目标不是解释产品功能，而是在 1-3 秒内让普通投资者停下来：

> 这条视频在讲我正在看的股票，而且它像一个懂市场的伙伴在提醒我。

Sentinel AI 的视频气质应该是“手机里的市场助理”，不是遥远的华尔街宣传片。画面和声音先抓住用户，产品再作为解释噪音、整理上下文的助手出现。

## 用户视角

TikTok / Shorts 上的潜在用户通常不是来听完整分析的。他们想快速判断：

- 这个票现在是不是值得我继续看？
- 为什么大家突然都在说它？
- 我是不是错过了什么？
- 哪些内容是噪音，哪些内容是真正变化？
- 有没有一个工具能替我过滤，而不是继续给我更多信息？

因此每条视频都围绕一个具体 ticker、一个具体情绪和一个具体状态变化，不做泛泛的品牌介绍。

## 视觉方向

### 必须像普通用户会看到的东西

画面优先使用生活化、手机化、社交化素材：

- 普通人在地铁、办公室、卧室、咖啡店看手机
- 手机通知弹出，而不是宏大的交易大厅
- X / Reddit / YouTube / 新闻标题形成信息噪音
- 行情 App、watchlist、K 线、价格跳动
- Sentinel AI 像伙伴一样把噪音压缩成一个清晰提醒

可以出现交易屏、行情墙、金融终端，但只能作为背景压力，不作为主角。主角是“用户正在被信息轰炸，Sentinel AI 帮他看清楚”。

### 画面结构

标准 30 秒结构：

| 时间 | 画面 | 用户感受 |
| --- | --- | --- |
| 0-2s | 手机震动、ticker 暴动、社交弹幕闪过 | 这个和我正在看的股票有关 |
| 2-6s | X / Reddit / 新闻 / 价格快速叠加 | 信息太多，看不清 |
| 6-10s | 画面压暗，Sentinel AI 推送浮上来 | 有人帮我过滤 |
| 10-22s | 三个信号逐条 reveal | 我知道该看什么了 |
| 22-27s | 产品界面展示完整 context preview | 这不是喊单，是上下文 |
| 27-30s | 轻 CTA | 我可以关注或点进去看更多 |

### 视觉关键词

要像：

- 手机里的市场助理
- 朋友提醒你别被噪音带跑
- 普通投资者每天会看到的股票信息流
- 冷静、清晰、有一点紧张感
- 真实生活 + 社交噪音 + 产品提醒

不要像：

- 遥远的华尔街大片
- 金融 SaaS 官网宣传片
- PPT 信息卡
- 股票老师讲课
- 纯字幕搬运

## 声音方向

声音由三层组成。

### 1. 旁白 VO

旁白是视频主线，语气像一个冷静的市场伙伴：

- 低频、可信、克制
- 句子短
- 不喊单
- 不制造暴富幻想
- 像在提醒用户“先看清楚”

示例：

```text
NVDA moved again.

Everyone saw the price.
Most people missed the state change.

X is loud.
Reddit is louder.

Sentinel AI flagged it:
HEATED.

Not a buy signal.
A context signal.
```

### 2. 背景音乐 BGM

BGM 要有低频脉冲和轻微紧张感，但不能盖过旁白：

- 暗色电子
- 低频 pulse
- 轻微 heartbeat
- 关键状态出现时短暂停顿
- VO 出现时自动 ducking

### 3. 音效 SFX

每个关键视觉事件都要有声音反馈：

- 手机震动
- notification pop
- whoosh 转场
- glitch
- data scan
- ticker tick
- low boom
- signal lock

## 素材来源策略

### 优先级 1：公开可商用素材库

优先使用许可清晰的素材库：

- Pexels：视频和图片可免费商用，通常无需署名，但不能暗示人物或品牌背书。
- Pixabay：图片、视频、音乐、音效可用于商业项目，但不能未修改后单独转售或作为素材库再分发。
- Coverr：用于 B-roll 视频素材。

适合下载：

- 手机使用场景
- 办公室 / 通勤 / 夜晚刷手机
- 股票图表 / 电脑屏幕 / 金融数据
- 城市夜景 / 桌面 / 键盘
- 抽象数据流 / 服务器 / AI 背景

### 优先级 2：YouTube / 新闻公开视频

下载工具使用 `yt-dlp`，当前本机安装版本：

```powershell
uv tool run yt-dlp --version
```

使用原则：

- 只下载我们有权使用、Creative Commons、官方允许复用或明确授权的视频。
- 新闻公开视频可用于研究、拆解、内部参考和素材灵感。
- 未授权新闻片段不直接进入商业获客成片。
- 如果确实需要新闻画面，应优先做成：
  - 低细节模糊背景
  - 自制标题卡
  - 来源引用截图风格
  - 重新绘制的新闻摘要界面

推荐下载命令示例：

```powershell
uv tool run yt-dlp `
  --match-filters "license=Creative Commons Attribution license (reuse allowed)" `
  --write-info-json `
  --embed-metadata `
  --merge-output-format mp4 `
  -f "bv*+ba/b" `
  -o "docs/assets/source-videos/youtube/%(upload_date)s-%(id)s-%(title).80s.%(ext)s" `
  "YOUTUBE_URL"
```

### 优先级 3：AI 生成素材

当素材库找不到合适画面时，用 AI 生成：

- Sentinel AI 市场助理界面
- 社交噪音墙
- 手机推送特写
- 未来感 watchlist
- 抽象市场状态图

AI 生成素材必须保持生活化，不要生成过度科幻、过度华尔街化的画面。

## 合规边界

短视频输出必须包含：

- `Context, not financial advice.`
- 不使用 `buy now`、`sell now`、`guaranteed`、`100%` 等表达
- 不暗示素材中的人物、媒体、品牌背书 Sentinel AI
- 不把未授权新闻视频作为商业广告主体

## 下一步执行标准

下一版获客视频必须满足：

- 有旁白
- 有 BGM
- 有 SFX
- 有真实或公开素材画面
- 有产品 UI 动画
- 有普通用户生活场景
- 每 1-2 秒有视觉变化
- 3 秒内出现具体 ticker 和冲突
- 30 秒内完成一个状态变化故事
